Project 01

PersonalAI

AI agent

Local, security-first AI assistant for my laptop

PersonalAI is an AI agent that runs on my own laptop and controls it through voice and terminal commands. It can open and use Chrome, read and compose emails, and help with coding, with Ollama running a local model as its base AI.

  • Voice and terminal control: speak or type a command and the agent carries it out on the laptop.
  • Browser and email: opens and uses Chrome, and reads and composes emails.
  • Coding assistance: a coding assistant with its own web interface and controlled Git support.
  • Desktop and Office control: works with desktop apps and Microsoft Office.
  • Security first: the AI never gets unrestricted access to the shell, files or credentials. Sensitive actions go through bounded tools, validation and my approval before they run.
  • Remote access: I can reach the coding assistant from my Android phone over a private network.
